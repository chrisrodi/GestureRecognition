# GestureRecognition
Creating a neural network to work in tandem with a walking quad-legged robot do. This hand recognition will be used to give commands to the quad-legged bot.

# Libraries planned on using:
## OpenCV 

Used to capture frames from camera source and then processing the frames.

## MediaPipe

This is the engine that pre-processes the captured frames to then process hand-tracking, detection of finger orientation events.

## PyAutoGUI
Used to control mouse cursor and perform clicks based off of hand gestures.

## PyNput
Used for mouse and keyboard events. 

## NumPy
Used for numerical operations, distance calculations. Majority would be used for array handling.

## Time
Used to track time during execution

## Math
Using to calculate disance between angles on hand orientations and gestures
